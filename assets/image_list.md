# PAAVAI JEWELLERY — Image Assets Checklist

This checklist maps every product handle in `products_import.csv` to its recommended image filename, optimal upload resolution, and a direct Unsplash placeholder URL you can use until final product photography is ready.

**Important:** Unsplash placeholder images are for staging/demo purposes only. Replace every placeholder with licensed, brand-owned product photography before the store goes live — Unsplash images are not of the actual PAAVAI JEWELLERY products and must not be used in production commerce without checking each photo's license terms.

## Naming convention

Save files as `assets/products/{handle}-{sequence}.jpg`, e.g. `assets/products/amirtha-antique-gold-necklace-01.jpg`. Use sequence `-01` for the primary (featured) image and `-02`, `-03`, etc. for gallery/alternate angles.

## Recommended resolution

| Use case | Recommended size | Format | Notes |
|---|---|---|---|
| Product gallery (main) | 2000 × 2500 px (4:5) | JPG (quality 80–85) or WebP | Matches `.product-gallery__main` aspect ratio in theme.css |
| Product gallery (thumbnail) | auto-generated by Shopify CDN | — | Shopify serves resized versions via `image_url`; no manual thumb needed |
| Homepage hero banner | 2400 × 1350 px (16:9) or taller for mobile crop | JPG | Compress to under 400KB for LCP performance |
| Category strip tile | 900 × 1200 px (3:4) | JPG | |
| Best-sellers grid card | 1200 × 1500 px (4:5) | JPG | |

## How to apply these images in Shopify

1. **Product images (via CSV import):** The `Image Src` column in `products_import.csv` already points to the Unsplash placeholder URLs above, so Shopify will pull and attach them automatically the moment the CSV is imported under Settings → Products → Import.
2. **Swapping in real photography later:** Re-upload the product via Shopify Admin → Products → select product → Media → Add media, then delete the placeholder image. Keep the same `Image Alt Text` values (or update them) for SEO and accessibility.
3. **Theme images (hero, category tiles, brand story):** These are currently hardcoded as `<img src="...unsplash.com...">` tags inside `templates/index.liquid` so the homepage renders correctly out of the box. To make them editable from the Theme Editor, upload your final images under Settings → Files or through a section's image picker setting, then swap the hardcoded `src` for `{{ settings.hero_image | image_url: ... }}` (already wired up as a fallback pattern in `templates/index.liquid` for `settings.hero_image`).
